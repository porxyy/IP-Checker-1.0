# IP-Checker-1.0
A simple Bash script that displays your Local and Public IP address.

## Requirements
- Linux (any distro)
- curl installed

## Install curl (if you don't have it)
sudo apt install curl -y

## How to Use

### 1. Clone the repo
git clone https://github.com/porxyy/IP-Checker-1.0.git

### 2. Go into the folder
cd IP-Checker-1.0

### 3. Make the script executable
chmod +x myip.sh

### 4. Run it
./myip.sh

## Output Example
Local IP:   192.168.1.42
Public IP:  104.23.187.5
